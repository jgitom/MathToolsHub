# Sniper Elite Hunter — Arcade FPS Prototype

A browser-based HTML5 arcade shooting prototype for the SNIPER Games project.

## Run locally

1. Open the folder.
2. Double-click `index.html`.
3. For best results, run with a local server.

### macOS Terminal

```bash
cd sniper_elite_hunter
python3 -m http.server 8080
```

Then open:

```text
http://localhost:8080
```

## Controls

- Mouse: Aim
- Left click: Fire
- Right click or Space: Zoom
- Shift: Steady aim
- R: Reload
- Fullscreen button: Enter fullscreen

## Current features

- 60-second arcade mission
- Moving hostile and civilian targets
- Score, accuracy, waves, combo and precision bonuses
- Ammo and reload system
- Zoom scope and steady-aim mechanic
- Armored targets at higher waves
- Responsive layout and touch support
- Game-over statistics
