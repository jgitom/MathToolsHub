# Sniper Elite: Shadow Ops — MVP

A browser-based tactical sniper prototype built with plain HTML, CSS and JavaScript.

## Included

- Mission briefing screen
- Moving hostile and civilian targets
- Scope reticle
- Ammo and reload system
- Score and accuracy tracking
- Mission timer
- Headshot bonus
- Mission result screen
- Basic browser-generated sound effects
- Responsive interface

## Run

1. Extract the ZIP file.
2. Open `index.html` in Chrome, Edge, Firefox or Safari.
3. Click **Start Mission**.
4. Move the mouse to aim.
5. Left-click to fire.
6. Click **Reload** when ammunition is empty.
